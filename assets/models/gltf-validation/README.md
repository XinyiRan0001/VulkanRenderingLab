# Original glTF validation fixtures

Generated by `tools/generate_gltf_validation.py` using only the Python standard
library. Geometry and procedural texture data are original to this repository;
no third-party model or texture license is required.

`scene.gltf` uses external buffers/images; `scene.glb` embeds geometry and images.
Both contain three cube instances with two materials, hierarchical translation,
nonuniform scale and mirrored scale. The other glTF files intentionally exercise
rejection paths and are not demo scenes.

These are correctness fixtures, not a representative performance benchmark or
finished portfolio artwork.
